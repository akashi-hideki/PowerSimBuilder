# PowerSimBuilder Demo Scripts

Two closed-loop control demos using existing components from
`src/python_runtime/components/` and StaTable-generated state machines.

## 1. PID + FirstOrderLag (standalone)

**File**: `demo_pid_first_order_lag.py`
**Output**: `pid_first_order_lag.png`

Standard PID controller + 1st-order lag plant.
Simple and deterministic: verifies the PID+plant closed loop works.

- **Result**: `final y = 0.9738` (target 1.0)
- **Components**: `PIDController`, `FirstOrderLag` (standard, not FMU)

Run:

```powershell
python examples\demos\demo_pid_first_order_lag.py
```

## 2. StaTable Runtime + External PID + ThermalMass

**File**: `demo_statable_runtime_loop.py`
**Output**: `statable_runtime_loop.png`

7-layer state machine (StaTable-generated) + external PID fills the
stub `F_StartOvenPid`, driving a ThermalMass plant.

- **Result**: `final T = 200.00 degC` (target 200) — exact convergence
- **Components**:
  - `CookingHeaterController_powersim.build_runtime()` — 7 layers
  - `ExternalPID` (in-script) — fills the StaTable F_* stubs
  - `ThermalMass` — 1st-order thermal plant

Run:

```powershell
python examples\demos\demo_statable_runtime_loop.py
```

### Architecture

```
StaTableRuntime (7 layers)
    │ state machine (OvIdle -> PidHeating)
    │ runtime.globals: oven_target_temp / oven_current_temp / heater_top_duty
    ↓
External PID (in-script)
    │ error = target - measured
    │ duty = PID(error)
    ↓
ThermalMass plant
    │ heat_flow = duty * 1000 W
    │ dT/dt = (Q_in - Q_out) / C_th
    └──→ oven_current_temp -> runtime.globals (feedback)
```

**Note**: `CookingHeaterController_powersim.py` state transitions are fully
generated by StaTable, but the PID calculation functions (`F_StartOvenPid`,
`F_SetTopHeaterDuty`, etc.) are `return 0` stubs. This demo shows the
realistic hybrid pattern: StaTable handles the state machine, Python
handles the math. This is the intended extension point in the
`STABLE_USER_CODE` markers.


### StaTable 7 層の役割

| 層 | 役割 | イベント例 |
|---|---|---|
| DriverInput | センサ入力 | SENSOR_TICK, ZC_PULSE |
| DriverOutput | ヒータ・ファン出力 | HEAT_START, FAN_PUMP_START |
| MwMicrowave | 電子レンジ | MW_START, MW_ANODE_OK |
| **MwOven** | **オーブン（PID 制御対象）** | **OV_START → PidHeating** |
| MwGrill | グリル | GR_START, GR_OVERHEAT |
| MwSteam | スチーム | ST_START, ST_PUMP_TICK |
| Application | 調理シーケンス | SEQ_RECEIVED, STAGE_DONE |

### ハイブリッドパターン（StaTable 連携の核心）

StaTable handles state transitions; Python handles control math.
`STABLE_USER_CODE_START/END` markers define the integration points.
This separation allows independent validation of state logic (StaTable) and
control tuning (Python).

**Why standalone instead of `.psbproj`**: the current GUI does not directly
support 7-layer state machines. `demo_statable_runtime_loop.py` is provided as a
`python`-executable demo. GUI integration (`.psbproj`) is planned for a future version.

**Public demo positioning**: StaTable integration is demonstrated by this standalone demo.
GUI PID demo is demonstrated by `oven_control.psbproj`. They are complementary.

## 4. OvenChamber + PID 閉ループ（`.psbproj`、GUI デモ）

**ファイル**: `oven_control.psbproj`

OvenChamber（StaTable オーブン庫内温度モデル）+ PID 制御の閉ループデモ。
ThermalMass を内部にラップし、ヒータ duty から庫内温度を計算します。

| 構成 | 内容 |
|---|---|
| コンポーネント | `OvenChamber` + `PID Controller` |
| 配線 | `PID.control → OvenChamber.heater_top_duty` / `OvenChamber.oven_current_temp → PID.measured` |
| setpoint | 200.0 °C |
| t_end | 300.0 s（`.psbproj` の `metadata.tEnd` に永続化） |

### PID パラメータ（no_aw チューニング）

| パラメータ | 値 | 根拠 |
|---|---:|---|
| kp | 0.01 | IMC ベース |
| ki | 0.0001 | τ=100s に整合 |
| kd | 0.0 | 1 次遅れのため不要 |
| anti_windup | False | オーバーシュート最小化 |

### OvenChamber パラメータ（既定値）

| パラメータ | 値 | 意味 |
|---|---:|---|
| thermal_resistance | 0.5 K/W | 断熱性能 |
| thermal_capacity | 200 J/K | 庫内熱容量 |
| ambient_temperature | 25.0 °C | 室温 |
| initial_temperature | 25.0 °C | 初期温度 |
| heater_power_max | 1000.0 W | ヒータ最大電力 |

### 期待される波形

| 指標 | 値 |
|---|---|
| 初期温度 | 25.0 °C |
| ピーク | 202.9 °C（オーバーシュート 1.45%） |
| 整定時間 | ~65 s（±2% バンド） |
| 定常値 | 200.68 °C（誤差 -0.68°C） |

温度が 25 → 200°C に上昇後、duty が 1.0 → ~0.35 に低下して安定（放熱との平衡）。

### 再現手順

1. `PowerSimBuilder.exe` 起動
2. **File → Open** → `examples\demos\oven_control.psbproj`
3. **Create Simulation**（非モーダルでエディタが開く）
4. `t_end (s):` が **300** で復元されていることを確認
5. **Run** → matplotlib グラフウィンドウに温度・制御波形

### 中身検証

```powershell
python tools\inspect_psbproj.py examples\demos\oven_control.psbproj
```
