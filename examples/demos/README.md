# PowerSimBuilder Demo Scripts

Two closed-loop control demos using existing components from
`src/python_runtime/components/` and StaTable-generated state machines.

## 1. PID + FirstOrderLag (standalone)

**File**: `demo_pid_first_order_lag.py`
**Output**: `pid_first_order_lag.png`

Standard PID controller + 1st-order lag plant.
Simple and deterministic: verifies the PID+plant closed loop works.

- **Result**: `final y = 0.9738` (target 1.0)
- **Components**: `PIDController`, `FirstOrderLag` (standard, not FMU)

Run:

```powershell
python examples\demos\demo_pid_first_order_lag.py
```

## 2. StaTable Runtime + External PID + ThermalMass

**File**: `demo_statable_runtime_loop.py`
**Output**: `statable_runtime_loop.png`

7-layer state machine (StaTable-generated) + external PID fills the
stub `F_StartOvenPid`, driving a ThermalMass plant.

- **Result**: `final T = 200.00 degC` (target 200) — exact convergence
- **Components**:
  - `CookingHeaterController_powersim.build_runtime()` — 7 layers
  - `ExternalPID` (in-script) — fills the StaTable F_* stubs
  - `ThermalMass` — 1st-order thermal plant

Run:

```powershell
python examples\demos\demo_statable_runtime_loop.py
```

### Architecture

```
StaTableRuntime (7 layers)
    │ state machine (OvIdle -> PidHeating)
    │ runtime.globals: oven_target_temp / oven_current_temp / heater_top_duty
    ↓
External PID (in-script)
    │ error = target - measured
    │ duty = PID(error)
    ↓
ThermalMass plant
    │ heat_flow = duty * 1000 W
    │ dT/dt = (Q_in - Q_out) / C_th
    └──→ oven_current_temp -> runtime.globals (feedback)
```

**Note**: `CookingHeaterController_powersim.py` state transitions are fully
generated by StaTable, but the PID calculation functions (`F_StartOvenPid`,
`F_SetTopHeaterDuty`, etc.) are `return 0` stubs. This demo shows the
realistic hybrid pattern: StaTable handles the state machine, Python
handles the math. This is the intended extension point in the
`STABLE_USER_CODE` markers.

## 3. PID + First Order Lag 閉ループ（`.psbproj`、GUI デモ）

**ファイル**: `pid_closed_loop.psbproj`

| 構成 | 内容 |
|---|---|
| コンポーネント | `PID Controller` + `First Order Lag` |
| 配線 | `PID.control → FOL.input` / `FOL.output → PID.measured` |
| setpoint | 1.0 |

### 再現手順

1. `PowerSimBuilder.exe` 起動
2. **File → Open** → `examples\demos\pid_closed_loop.psbproj`
3. **Create Simulation**（非モーダルでエディタが開く）
4. **Run** → matplotlib グラフウィンドウに PID 応答波形が表示

### 期待される波形

- setpoint=1 に収束
- オーバーシュート: 小（数 %）
- 整定後は定常偏差なし
