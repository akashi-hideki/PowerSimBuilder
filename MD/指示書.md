# シミュレーション基盤 設計指示書

## 1. 基本方針

* シミュレーションは **複数のコンポーネント（電源、整流、溶接機、故障装置、誘導電動機など）** を直列につなぐ方式で構成する。
* データの受け渡しは共通データ構造 `SimulationData` を利用する。
* **初期化処理**は各コンポーネントの `init(simdata)` に実装し、必要な `SimulationData` の項目をセットする。
* main関数は後で自動生成できるように、コンポーネントリストを順番に処理する形式に統一する。

---

## 2. データ構造

### SimulationData

```python
class SimulationData:
    def __init__(self):
        # 何もセットせず、各クラスの init() で初期化する
        self.voltage = None
        self.current = None
        self.frequency = None
        self.waveform = None
        
        self.diode_drop = None
        self.rectified_voltage = None
        self.ripple = None
        self.rectifier_type = None
        
        self.welding_current_set = None
        self.welding_current_actual = None
        self.welding_mode = None
        self.overheat = None
        
        self.short_circuit = None
        self.open_circuit = None
        self.inrush_current = None
        
        self.motor_rated_power = None
        self.motor_torque = None
        self.motor_speed = None
        self.slip = None
        
        self.time_step = None
        self.logs = []
```

👉 各項目は **Noneで初期化**し、必要に応じて各コンポーネントの `init()` で設定する。

---

## 3. 共通インタフェース

すべてのコンポーネントは以下を実装する。

```python
class BaseComponent:
    def init(self, simdata: SimulationData):
        """SimulationDataの初期化を行う"""
        raise NotImplementedError

    def update(self, simdata: SimulationData, time: float) -> SimulationData:
        """時間ごとの状態更新"""
        raise NotImplementedError
```

---

## 4. 各コンポーネント設計例

### 電源・発電機系

```python
class PowerSupply(BaseComponent):
    def __init__(self, voltage=200.0, current=10.0, frequency=50.0, waveform="sine"):
        self.voltage = voltage
        self.current = current
        self.frequency = frequency
        self.waveform = waveform

    def init(self, simdata):
        simdata.voltage = self.voltage
        simdata.current = self.current
        simdata.frequency = self.frequency
        simdata.waveform = self.waveform

    def update(self, simdata, time):
        # 単純化：電圧をそのまま保持
        simdata.voltage = self.voltage
        return simdata
```

### 整流・ブリッジ回路

```python
class Rectifier(BaseComponent):
    def __init__(self, diode_drop=0.7, rectifier_type="full"):
        self.diode_drop = diode_drop
        self.rectifier_type = rectifier_type

    def init(self, simdata):
        simdata.diode_drop = self.diode_drop
        simdata.rectifier_type = self.rectifier_type
        simdata.rectified_voltage = 0.0
        simdata.ripple = 0.0

    def update(self, simdata, time):
        # 簡易モデル：整流後電圧 = 入力電圧 - ダイオード降下
        if simdata.voltage is not None:
            simdata.rectified_voltage = max(0, simdata.voltage - self.diode_drop)
        return simdata
```

👉 溶接機、故障発生装置、誘導電動機も同じ構造で実装する。

## 5. メイン処理（自動生成を想定）

main関数は次のような構造で統一する：

```python
def main():
    simdata = SimulationData()

    components = [
        PowerSupply(voltage=220.0, frequency=50.0),
        Rectifier(diode_drop=0.7, rectifier_type="full"),
        WeldingMachine(current_set=120.0),
        FaultInjector(),
        InductionMotor(rated_power=5.0)
    ]

    # 初期化処理
    for comp in components:
        comp.init(simdata)

    # 時間ループ
    time_range = np.arange(0, 1.0, simdata.time_step or 0.001)
    for t in time_range:
        for comp in components:
            simdata = comp.update(simdata, t)
        simdata.logs.append({
            "time": t,
            "voltage": simdata.voltage,
            "current": simdata.current,
            "motor_speed": simdata.motor_speed
        })
```

👉 **自動生成ツール**は `components = [...]` の部分を生成すればよい。

---

## 6. ログ収集と可視化

* `simdata.logs` に時系列データを保存する。
* 後処理でグラフ化できるように辞書形式で保存する。

例：

```python
voltages = [log["voltage"] for log in simdata.logs]
times = [log["time"] for log in simdata.logs]
plt.plot(times, voltages)
```

## まとめ

* **SimulationDataはNoneで初期化 → 各クラスの`init`でセット**
* **updateはSimulationDataを受け取り更新して返す**
* **mainはコンポーネントリストをループするだけの構造にして自動生成しやすくする**

---

この形なら「ツールでmainを自動生成 → シナリオに応じてクラスを差し替え」も簡単にできます。
