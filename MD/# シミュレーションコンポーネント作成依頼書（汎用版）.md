# シミュレーションコンポーネント作成依頼書（汎用版）

## 1. 依頼概要

電力系統シミュレーションシステム向けの各種コンポーネント作成を依頼します。本指示書はダイオードブリッジ整流回路、LCフィルタ回路、その他電力系統コンポーネントの開発に使用できる汎用テンプレートです。

## 2. 基本仕様（全コンポーネント共通）

- **ベースクラス**: Component (component_base.pyを継承)

```python
class Component(ABC):
    """コンポーネントの共通ベースクラス"""
  
    def __init__(self, comp_id: str, comp_type: str):
        self.id = comp_id
        self.type = comp_type
        self.inputs: Dict[str, Any] = {}
        self.outputs: Dict[str, Any] = {}
        self.parameters: Dict[str, Any] = {}
  
    @abstractmethod
    def update(self, t: float, dt: float, sim_data: Any) -> None:
        """コンポーネントの状態を更新する抽象メソッド"""
        pass
  
    def get_status(self) -> Dict[str, Any]:
        """コンポーネントの現在の状態を取得"""
        return {
            'id': self.id,
            'type': self.type,
            'inputs': self.inputs,
            'outputs': self.outputs,
            'parameters': self.parameters
        }


class YourComponentName(Component):
    def __init__(self, name: str, parameters: dict = None):
        super().__init__(name, parameters)
        # 初期化コード

    def update(self, t: float, dt: float, sim_data: dict):
        # 更新コード
   

- **入力/出力ポート**: 標準化された辞書形式
- **更新メソッド**: update(t, dt, sim_data) の実装必須
- **パラメータ管理**: パラメータ辞書の適切な管理
- **互換性**: MAINループシステムとの完全互換性
