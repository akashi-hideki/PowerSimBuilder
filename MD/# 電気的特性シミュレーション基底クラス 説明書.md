# 電気的特性シミュレーション基底クラス 説明書

## 概要

この基底クラスは、電気的特性シミュレーション（特に誘導電動機、チョッパ制御、LCフィルタ）を行うためのフレームワークを提供します。C/C#経験者向けに設計されており、型ヒントを積極的に使用しています。

## クラス構成図

```
ElectricalSimulationBase (抽象基底クラス)
    ├── ElectricalComponent (データクラス)
    ├── ElectricalComponentType (列挙型)
    ├── ComponentConnection (列挙型)
    └── InductionMotorSimulation (具体クラス)
```

## 主要コンポーネント

### 1. ElectricalComponentType (列挙型)
電気部品の種類を定義します。

| 種類 | 説明 |
|------|------|
| RESISTOR | 抵抗器 |
| INDUCTOR | インダクタ（コイル） |
| CAPACITOR | キャパシタ（コンデンサ） |
| VOLTAGE_SOURCE | 電圧源 |
| CURRENT_SOURCE | 電流源 |
| SWITCH | スイッチ（チョッパ制御用） |
| DIODE | ダイオード |
| MOTOR | 誘導電動機 |

### 2. ElectricalComponent (データクラス)
電気部品のパラメータを保持します。

```python
component = ElectricalComponent(
    name="FilterInductor",
    component_type=ElectricalComponentType.INDUCTOR,
    value=0.001,  # 1mH
    connection=ComponentConnection.SERIES,
    nodes=(1, 2),
    is_active=True
)
```

### 3. ElectricalSimulationBase (抽象基底クラス)
シミュレーションの核心機能を提供します。

## 使用方法

### ステップ 1: シミュレーションの設定

```python
# モータパラメータの定義
motor_params = {
    'stator_resistance': 0.1,      # 固定子抵抗 [Ω]
    'rotor_resistance': 0.15,      # 回転子抵抗 [Ω]
    'stator_inductance': 0.01,     # 固定子インダクタンス [H]
    'rotor_inductance': 0.01,      # 回転子インダクタンス [H]
    'mutual_inductance': 0.009,    # 相互インダクタンス [H]
    'inertia': 0.1,                # 慣性モーメント [kg·m²]
    'pole_pairs': 2,               # 極対数
    'load_torque': 5.0,            # 負荷トルク [Nm]
    'damping': 0.01                # ダンピング係数
}

# シミュレーションインスタンスの作成
sim = InductionMotorSimulation(
    motor_params=motor_params,
    dt=1e-5,      # 時間刻み幅 [s]
    max_time=0.1   # 最大シミュレーション時間 [s]
)
```

### ステップ 2: 回路の構築

```python
# 電源の追加
sim.add_component(ElectricalComponent(
    name="Source", 
    component_type=ElectricalComponentType.VOLTAGE_SOURCE, 
    value=100,    # 100V
    nodes=(0, 1)
))

# LCフィルタの追加
sim.add_component(ElectricalComponent(
    name="FilterInductor", 
    component_type=ElectricalComponentType.INDUCTOR, 
    value=0.001,  # 1mH
    nodes=(1, 2)
))

sim.add_component(ElectricalComponent(
    name="FilterCapacitor", 
    component_type=ElectricalComponentType.CAPACITOR, 
    value=0.0001,  # 100μF
    nodes=(2, 0)
))

# チョッパ制御用スイッチの追加
sim.add_component(ElectricalComponent(
    name="ChopperSwitch", 
    component_type=ElectricalComponentType.SWITCH, 
    value=0,  # スイッチなので値は不要
    nodes=(2, 3),
    is_active=True
))
```

### ステップ 3: シミュレーションの実行

```python
# コールバック関数の定義（進行状況の監視）
def monitor(sim, step):
    if step % 10000 == 0:
        rpm = sim.motor_speed * 60 / (2 * np.pi)
        print(f"Time: {sim.time:.4f}s, Speed: {rpm:.1f}RPM")

# シミュレーション実行
sim.run(callback=monitor)
```

### ステップ 4: 結果の可視化と保存

```python
# 結果のプロット
sim.plot_results(save_path="simulation_results.png")

# データの保存
sim.save_data("simulation_data.csv")
```

## 出力グラフ

シミュレーション結果として、以下のグラフが生成されます：

1. **ノード電圧**: 各ノードの電圧変遷
2. **ブランチ電流**: 各ブランチの電流値
3. **モーター速度**: 回転速度の時間変化（RPM）
4. **モータートルク**: トルクの時間変化（Nm）
5. **モーター電流**: 各相の電流値（A）
6. **キャパシタ電圧**: コンデンサの電圧変遷

## パフォーマンス最適化のヒント

1. **時間刻み幅の調整**: シミュレーションの精度と速度のバランスを取ります
2. **NumPyの活用**: ループではなくベクトル化演算を使用します
3. **スパース行列の利用**: 大規模な回路ではスパース行列ソルバーを使用します
4. **並列処理**: 複数のシナリオを並列で実行します

## トラブルシューティング

| 問題 | 解決方法 |
|------|----------|
| 発散するシミュレーション | 時間刻み幅を小さくする |
| 遅いシミュレーション | ベクトル化を確認、不要なデータ記録を減らす |
| 不正確な結果 | 物理モデルとパラメータを再確認 |

## 数学的背景

このシミュレーションは以下の数学的モデルに基づいています：

1. **電気回路方程式**: キルヒホッフの法則、オームの法則
2. **誘導電動機のd-qモデル**: Park変換、Clark変換
3. **機械系方程式**: トルク平衡方程式、運動方程式
4. **制御理論**: PID制御、PWM制御
