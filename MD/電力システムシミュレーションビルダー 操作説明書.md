## 1. 概要
電力システムシミュレーションビルダーは、電力システムのモデリングとシミュレーションを行うためのビジュアルツールです。直感的なドラッグ＆ドロップ操作でシステムを構築し、Pythonコードを自動生成してシミュレーションを実行できます。

主な機能:
- コンポーネントベースのシステム設計
- 自動接続管理
- Pythonシミュレーションコードの自動生成
- システム構成の保存/読み込み
- 熱パラメータや故障条件の設定

## 2. システム起動
1. アプリケーションを起動するとメインウィンドウが表示されます
2. 左側にコンポーネントパレット、中央にデザインキャンバス、右側にプロパティパネルが表示されます
3. 初期状態ではサンプルコンポーネントがパレットに登録されています

## 3. 画面構成
![画面構成図](ui-layout.png)

| 領域 | 説明 |

| **ツールバー** | ファイル操作、実行、配置整理などの主要機能 |

## 4. 基本操作

### 4.1 コンポーネントの追加
1. コンポーネントパレットから追加したいコンポーネントを選択
2. 以下のいずれかの方法で追加:
   - 「追加」ボタンをクリック（キャンバス中央に追加）
   - コンポーネントをドラッグしてキャンバス上にドロップ
3. 追加されたコンポーネントはキャンバス上に表示されます

### 4.2 コンポーネントの接続
1. 出力ポート（コンポーネント右側の緑色の丸）をクリック
2. 入力ポート（別のコンポーネント左側の青色の丸）をクリック
3. 接続線が自動的に作成されます

![接続手順](connection-process.gif)

### 4.3 コンポーネントの移動
1. 移動したいコンポーネントをクリックして選択
2. コンポーネントをドラッグして新しい位置に移動
3. 接続線は自動的に更新されます

### 4.4 プロパティの編集
1. 編集したいコンポーネントを選択
2. 右側のプロパティグリッドにパラメータが表示されます
3. 各パラメータの値を編集
4. 変更は即時反映されます

### 4.5 削除操作
1. 削除したいコンポーネントまたは接続線を選択
2. ツールバーの「削除」ボタンをクリック
3. またはキーボードのDeleteキーを押す

## 5. 高度な操作

### 5.1 自動配置
1. ツールバーの「配置整理」ボタンをクリック
2. システムが自動的に最適な配置に整理されます
3. 特に複雑なシステムで有効です

### 5.2 カスタムコンポーネントの作成
1. ツールバーの「コンポーネント追加」ボタンをクリック
2. コンポーネント情報を入力:
   - 名前
   - タイプ
   - カテゴリ
   - パラメータ
   - ポート情報
3. 「OK」をクリックすると新しいコンポーネントがパレットに追加されます

### 5.3 故障条件の設定
1. 故障監視システムコンポーネントを選択
2. プロパティグリッドで「Conditions」をダブルクリック
3. 故障条件エディタが開きます
4. 監視対象コンポーネントと状態を設定
5. 条件を追加して「OK」をクリック

## 6. シミュレーション実行
1. システム設計が完了したらツールバーの「実行」ボタンをクリック
2. 生成されたPythonコードがプレビューウィンドウに表示されます
3. シミュレーションが自動的に実行されます
4. 結果はコンソールに表示されます

## 7. ファイル操作

| 操作 | 方法 |
|------|------|
| **新規作成** | ファイルメニュー > 新規作成 または Ctrl+N |
| **保存** | ファイルメニュー > 保存 または Ctrl+S |
| **読み込み** | ファイルメニュー > 開く または Ctrl+O |
| **エクスポート** | ファイルメニュー > Pythonコードをエクスポート |

## 8. ショートカットキー

| ショートカット | 機能 |
|----------------|------|
| Ctrl + Z | 元に戻す |
| Ctrl + Y | やり直す |
| Delete | 選択項目を削除 |
| Ctrl + C | 選択コンポーネントをコピー |
| Ctrl + V | コンポーネントを貼り付け |
| F5 | シミュレーション実行 |
| Ctrl + F | 自動配置 |

---

**注意事項**
- 保存は定期的に行ってください
- 複雑なシステムは小規模に分割して設計することを推奨
- シミュレーション実行中は操作しないでください

この操作説明書はバージョン1.0に基づいています。最新の情報についてはアプリケーション内のヘルプを参照してください。
