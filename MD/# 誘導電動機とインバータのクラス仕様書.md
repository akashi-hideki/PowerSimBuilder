### 3.2 制御シナリオ例

```python
# V/f制御シナリオ
def v_f_control_scenario():
    # 基本V/f曲線: V = 4.0 * f (50Hzで200V)
    base_voltage = 200.0
    base_frequency = 50.0
    v_f_ratio = base_voltage / base_frequency
    
    # 周波数指令に応じた電圧指令の計算
    frequency_command = controller.outputs.frequency_command
    voltage_command = v_f_ratio * frequency_command
    
    # 低周波数領域での電圧ブースト
    if frequency_command < 10.0:
        voltage_boost = 20.0 * (1 - frequency_command / 10.0)
        voltage_command += voltage_boost
    
    return voltage_command

# ベクトル制御シナリオ
def vector_control_scenario():
    # 速度制御器の出力からトルク電流指令を計算
    speed_error = controller.inputs.speed_reference - controller.inputs.actual_speed
    torque_current = speed_controller.update(speed_error)
    
    # 励磁電流指令は固定または弱め磁束制御
    if controller.inputs.actual_speed > controller.parameters.base_speed:
        # 弱め磁束制御領域
        flux_current = controller.parameters.rated_flux_current * \
                      (controller.parameters.base_speed / controller.inputs.actual_speed)
    else:
        # 定格磁束領域
        flux_current = controller.parameters.rated_flux_current
    
    return [flux_current, torque_current]
```

## 4. モデリングの詳細

### 4.1 誘導電動機の数学モデル

```
dq軸変換による状態方程式:

dψ_ds/dt = V_ds - R_s * i_ds + ω_e * ψ_qs
dψ_qs/dt = V_qs - R_s * i_qs - ω_e * ψ_ds
dψ_dr/dt = -R_r * i_dr + (ω_e - ω_r) * ψ_qr
dψ_qr/dt = -R_r * i_qr - (ω_e - ω_r) * ψ_dr

トルク方程式:
T_e = (3/2) * P * (ψ_ds * i_qs - ψ_qs * i_ds)

運動方程式:
J * dω_r/dt = T_e - T_l - B * ω_r
```

### 4.2 インバータの変調方式

```
正弦波PWM:
変調波: V_m * sin(ω*t)
キャリア波: 三角波またはのこぎり波
出力電圧: V_dc * (0.5 + 0.5 * m * sin(ω*t))

スペースベクトルPWM:
8つの基本ベクトルを使用
目的の電圧ベクトルを2つの隣接ベクトルで合成
デューティ比計算: T1, T2, T0
```

## 5. 実装の注意点

1. **数値積分の安定性**: 状態方程式の離散化に適切な方法（オイラー法、ルンゲクッタ法等）を選択
2. **スイッチング周波数の考慮**: シミュレーション時間ステップがスイッチング周期より十分小さいことを確認
3. **初期値の設定**: 電動機の始動時やインバータの初期状態を適切に設定
4. **過渡現象の再現**: 突入電流、スイッチング過電圧などの過渡現象を適切にモデル化
5. **リアルタイム性**: 計算負荷を考慮し、リアルタイムシミュレーションが可能なように最適化
