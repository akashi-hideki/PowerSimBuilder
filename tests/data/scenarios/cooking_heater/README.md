# cooking_heater

StaTable-based cooking heater controller integrated with a thermal model.

## Files

- design.xml               -- original StaTable design (CookingHeaterController, 7 layers).
- controller_box.py        -- Python code generated by PowerSimBuilder from design.xml.
- controller_box_demo.py   -- same with XML action injection for E2E.

## Test

tests/python/test_scenario_cooking_heater.py

- Loads controller_box.py via ControllerBox(generated_path=...).
- Verifies build_runtime() yields 7 layers.
- Drives 5 s with a HeaterBlock feedback loop.
- Asserts heater warms above initial 25 degC.
