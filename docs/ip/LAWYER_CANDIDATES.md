## 1. 本プロジェクトの位置づけ

PowerSimBuilder は **StaTable のシミュレーション・コンパニオン** です。
IP 相談は StaTable と共通の窓口で実施するため、候補リスト・選定基準・
費用目安は **StaTable 側の文書を正** とします。

## 2. PowerSimBuilder 固有の相談事項（追加分）

StaTable の相談事項に加えて、以下を確認予定:

| # | 相談内容 | 理由 |
|:---:|---|---|
| 1 | **StaTable との一体性** | コンパニオンツールとして配布する際の著作権帰属 |
| 2 | **シミュレーション機能の特許性** | FMU 実行 + 状態機械の組合せ（設計段階・未実装） |
| 3 | **.NET / fmpy の OSS ライセンス** | Apache-2.0 + BSD-2-Clause の商用配布（fmpy は将来の依存） |
| 4 | **中国企業へのライセンス** | StaTable と同様の懸念 |

## 3. 選定基準（StaTable と同一）

StaTable の `LAWYER_CANDIDATES.md` §1 を参照:

- ソフトウェア・IT 法務
- 国際取引（中国）
- 個人・中小企業の相談実績
- 秘密保持・競業避止
- 会社と無関係な事務所
- オンライン相談可
- 初回相談の費用が明確
